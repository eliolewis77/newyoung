租房避坑

押金刚交出去，就该想清楚怎么拿回来。签约、押金、维修、涨租、退租——每个坑都有对应的法条，和一句你能照着说的话。

  • 签约：租期 6 个月以上必须书面。没签书面合同又确定不了租期的，直接视为不定期租赁，双方都能随时解除——最不稳的一种。民法典 第707条合同里至少写清：租金和押金数额、支付方式、租期、谁负责维修、水电燃气物业费谁交、违约责任。
  • 隔断房 / 群租是违法的。以原设计的房间为最小出租单位；厨房、卫生间、阳台和地下储藏室不得出租住人。商品房屋租赁管理办法 第8条租到隔断房，可能被要求限期拆除、合同无效，押金还难追。看房时先确认是不是原始户型。
  • 押金：扣钱要有依据和凭证。法律没规定押金上限，常见押一付一、押一付三。退租时押金应当返还；正常使用的损耗（墙面轻微泛黄、家具自然老化）你不赔。民法典 第710条民法典 第733条拿不出维修票据的"天价损耗清单"，不该认。
  • 维修默认是房东的义务。房东不修，你可以要求他在合理期限内修；他仍不修，你可以自行维修，费用由房东负担，影响使用的还能要求减租或延长租期。但你自己弄坏的不算。民法典 第712条民法典 第713条
  • 租期内房东不能单方面随意涨租。商品房屋租赁管理办法 第9条续租时涨多少，看合同约定；没约定就重新协商，谈不拢就走人。
  • 转租 / 二房东必须拿到书面同意。民法典 第716条商品房屋租赁管理办法 第11条二房东没经房东同意就转租，房东可以解除合同、收回房屋——你交了租金也可能得搬。租二房东的房，一定要看原租赁合同和房东的书面同意。
  • 买卖不破租赁。房东把房子卖了，你的租约继续有效，新房主不能赶你走。民法典 第725条房东卖房要在出卖前合理期限内通知你，你在同等条件下有优先购买权，通知后 15 天内没表态才算放弃。民法典 第726条
  • 提前退租的违约金，过高可以要求减少。一般按合同约定赔，但违约金过分高于实际损失的，可以请求法院或仲裁机构适当减少。民法典 第585条
  • 房子危及安全或健康（如甲醛严重超标、结构危险），你可以随时解除。即使签约时你已经知道这房子有问题，也不影响解除权。民法典 第731条
  • 到期续租：租期满了你继续住、房东没提异议，原合同继续有效但变成不定期租赁；并且作为房屋承租人，你在同等条件下享有优先承租权。民法典 第734条
  • 这几类房子根本不能出租：违法建筑、不符合安全 / 防灾强制性标准、违规改变使用性质的房屋。商品房屋租赁管理办法 第6条
  • 警惕"租金贷"和长收短付跑路。近年长租公寓爆雷，二房东 / 公寓收你年付却按月付给真房东，资金链一断就跑路，你既被赶又拿不回钱；更隐蔽的是诱导你办"租金贷"，把房租变成贷款、逾期还上征信。尽量月付 / 季付，对"押一付十二还打折"的优惠保持警惕。
  • 假房东 / 无权出租先核证件。拿不出房产证原件和房东身份证，或二房东没有原租赁合同 + 房东书面同意，就敢收钱——真房东一出现，租约可能不被认、钱也要不回。签约前核对房产证、房东身份；租二房东的房必须看到原合同和书面同意。
  • 逐条看合同，别被"格式条约"带过。"到期自动续约""逾期一天天价违约金""退租需提前数月通知否则扣全部押金"这类条款，签字前就要划掉或拒绝。违约金过分高于实际损失的，可请求法院或仲裁机构适当减少。民法典 第585条

小 G 退租时，房东拿着手电筒一寸一寸照墙，列出一张近万元的"损耗赔偿清单"，说要从押金里扣完、还得补钱。小 G 翻出入住当天拍的全屋视频、水电表读数和合同里"按现状交付"的条款：墙面正常泛黄、家具自然老化不是损坏，而且房东拿不出任何维修票据。最后房东只扣了两百块清洁费，押金其余全额退回。

你能照着说的话

催维修："房东您好，卫生间漏水已经影响正常使用了，我在微信上催过两次。麻烦您本周内安排维修；如果周五前还没处理，我按民法典第 713 条自行找人维修，费用凭票据由您承担，并从下期租金中扣除，麻烦确认一下。"

被扣押金："扣押金请给我维修发票或正规报价单。正常使用的损耗按民法典第 710 条我不承担赔偿责任，麻烦把扣除明细和凭证发我，我们按合同来。"

留证清单
  • 合同原件，双方签字，含押金 / 维修责任 / 违约条款
  • 入住当天全屋视频或照片：墙面、家具、家电、水电燃气表读数
  • 押金、租金走转账并备注用途，尽量别付现金
  • 房东身份证明、房产证或授权；二房东要看原合同 + 房东书面同意
  • 所有沟通落文字（微信 / 短信），催修、催退押金都要留痕
  • 退租当天再拍一遍全屋，双方在场签交接单
  • 水电燃气、物业费结清凭证
遇到问题如何维权 · 四步走
  1. 先固定证据。合同、转账记录、入住 / 退租全屋视频、催修和催退押金的聊天记录、各类票据，全部留好。没证据，后面每一步都被动。
  2. 书面协商并给合理期限。把问题和依据（法条 / 合同）写在微信里发过去，写明"请在 X 日前处理，否则走下一步"。留痕本身就是施压。
  3. 找对渠道投诉或调解。小纠纷优先街道 / 社区人民调解（免费、出结果快）；隔断群租、违规出租找住建 / 房管；中介乱象找 12315；不清楚找谁就打 12345 转派。
  4. 硬手段兜底。押金拿不回、金额不大，走法院小额诉讼（诉讼费很低、很多地方可网上立案）；遇暴力驱逐、撬锁清退直接 110 报警，别自己硬扛。
租房去哪投诉

先协商、留证据，谈不拢再走下面的渠道。金额小的纠纷优先用调解和小额诉讼，成本低。

住建 / 房管部门
  • 房屋租赁纠纷的主管部门，租赁登记备案也在这里办
  • 隔断群租、违规出租可直接举报
  • 各地叫法不同：住建局 / 房管局 / 住房和城乡建设委员会
12345 政务服务便民热线
  • 租房纠纷、隔断群租、中介乱象都能打
  • 会转派属地街道和主管部门处理并回访
  • 适合"不知道该找哪个部门"的情况
12315 / 消费者协会
  • 针对中介服务：虚假房源、乱收中介费、不履约
  • 投诉前留好合同、付款凭证、聊天记录
街道 / 社区人民调解委员会
  • 免费调解，出结果快，不伤和气
  • 押金、小额赔偿类纠纷性价比最高
  • 调解协议可申请司法确认，有强制执行力
法院 / 小额诉讼
  • 押金、租金纠纷金额小的走小额诉讼，诉讼费很低
  • 流程简化，很多地方可网上立案
  • 拿不到押金时最硬的一条路
派出所 / 110
  • 遭遇暴力驱逐、强行清退、撬锁换锁、非法侵入住宅
  • 涉及人身安全直接报警，不要自己硬扛

提示：各地租房管理细则不同（如群租标准、备案要求），具体以当地住建部门口径为准。遇到复杂或金额较大的纠纷，建议咨询 12345、属地住建部门、法律援助机构或执业律师。
