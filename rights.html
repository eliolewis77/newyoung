维权渠道与证据

忍是解决不了问题的，但乱忍会过期。知道去哪、留什么、什么时候必须动。

劳动争议调解仲裁法 第27条
  • 渠道：劳动监察大队（投诉）、劳动人事争议仲裁委员会（仲裁，一般前置）、法院；热线 12333；可找工会 / 法律援助。
  • 上市公司：若公司是 A股 / 港股 / 美股上市公司，劳动违规（欠薪、强制加班、不缴社保、重大工伤）可向其上市交易所的投诉举报平台（上交所 / 深交所 / 港交所）及证监会 12386 热线举报。重大劳动纠纷属上市公司应披露事项，交易所通常会跟进。
  • 海外合作（ESG）：若公司与欧洲等海外企业有供应或合作关系，很多外企设有供应商行为准则与 ESG / 合规举报热线（whistleblowing）。劳动者可向合作方的 ESG 渠道举报中方公司的用工违规，外企一般会对供应商施压整改——对代工、外贸、出海企业尤其有效。
  • 仲裁时效 1 年，从你知道权利被侵害起算；在职期间欠薪不受 1 年限制，但离职后 1 年内要提出。
  • 证据为王：合同、工资条 / 流水、考勤、微信 / 邮件、工牌、社保记录、解除通知。

小 D 被欠薪，怕得罪领导一直忍，离职 2 年后才想维权。——很可能已过仲裁时效，钱难要回。

小 F 在一家给欧洲品牌代工的工厂，长期被强制加班还没加班费。他查到品牌官网有"供应商行为准则"举报入口，把考勤和聊天记录提交上去——品牌方随即向工厂发函要求整改，拖欠的加班费很快就补了。上市公司、有海外大客户的厂，往往比你想象中更怕"被曝光"。

通用方法（适用任何外企）
  • 去该品牌官网搜 "Speak Up" / "Ethics" / "Supplier Code of Conduct"
  • 代工、外贸、出海企业的海外大客户大多有举报入口
  • 提交考勤、聊天记录等用工违规证据

提示：渠道信息可能随机构调整变化，使用前请到对应官网核对最新入口。这些渠道是补充施压手段，劳动纠纷的法定主路径仍是劳动监察 / 仲裁 / 诉讼。

行动顺序

先收集证据 → 向劳动监察大队投诉或申请仲裁 → 不服仲裁结果再起诉。上市公司、有海外客户的，可同时走交易所举报 / ESG 渠道施压，多条线并行不冲突。别随便退群、删聊天记录。

平时就做
  • 工资条、排班表定期截图备份
  • 重要沟通尽量落到文字（微信 / 邮件）
  • 合同、协议自己留一份原件
  • 解除劳动关系全程留痕
  • 留意公司是否上市、是否有海外大客户（维权时多一条线）
