把法条变成你能直接用的数字

结果仅供参考，具体以当地最新规定和官方口径为准。

离职补偿金速算（N / 2N）

填好上面两项，点"算一下"。
N 规则：满1年=1个月；超6个月不满1年按1年；不满6个月=半月。超社平3倍则按3倍封顶、年限最高12年。

加班费计算器

填月薪和加班小时数，点"算加班费"。
时薪 = 月薪 ÷ 21.75 ÷ 8；倍数：平日1.5 / 休息日2 / 法定3.

退休时间计算器

填出生年月和身份，点"算退休时间"。
基于 2024 年渐进式延迟退休办法（2025-01-01 施行）通用算法估算；弹性退休可自愿前后不超 3 年，精确到月以官方对照表 / 12333 为准。

退休金估算器

填完所有项，点"估算月养老金"。
基础=(社平×(1+指数)/2×年限×1%)；个人=账户额÷计发月数。估算值，以社保局核算为准。

退租押金结算器

填押金金额，其他项没有就填 0，点"算能退多少"。
押金应当返还，扣钱要有依据和凭证。正常使用的损耗不用赔（民法典第710条）；违约金过分高于实际损失的可请求减少（第585条）。

工资条解读器

把工资条上"社保 / 公积金代扣"几栏的数字填进来，自动标出比例对不对、基数有没有低于下限。

填好基数和代扣金额，点"解读工资条"。
个人比例参考：养老 8% / 医疗 2% / 失业 0.5% / 公积金 5%–12%（前三项合计约 10.5%，公积金另算）。单位应按时足额缴纳（社保法 第60条），公积金也应足额缴存（公积金条例 第20条）。

入职 / 在职证据自查清单

  • 我手里有一份签字盖章的劳动合同原件
  • 我知道自己的试用期时长和工资标准（书面）
  • 工资按月发放，有工资条 / 银行流水
  • 单位给我缴了社保和公积金（可查）
  • 加班有记录，没给加班费我留了证
  • 重要沟通尽量落在微信 / 邮件文字
  • 如果签了竞业协议，单位按月给补偿
  • 解除劳动关系会有书面通知，不全信口头
